Solutions are stored in the [challenges](./challenges) folder. File names use the section and challenge number, for example `cs38.c12.py` is CS38 Challenge 12.

## Running a challenge

Run a solution from the repository root:

```powershell
python ".\challenges\cs38.c12.py"
```

Replace the file name with the challenge you want to run. Some file-handling challenges require the related text file to be present or may create it when run.
